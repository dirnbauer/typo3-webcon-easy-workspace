# TYPO3 docs report - before

Date: 2026-05-16 15:55:03 Europe/Vienna

Scope: README and extension documentation for TYPO3 14.

Findings:

- README documents the extension behavior and TYPO3 14 requirement.
- Documentation uses Markdown rather than docs.typo3.org reStructuredText structure.
- README contains a v14-only claim but also references older fallback behavior.
- Discard documentation showed the legacy `version => flush` DataHandler command.
- Documentation does not mention local quality commands.

Suggested changes:

- Update README and documentation to state TYPO3 14.3+ only.
- Document `DataHandler` `discard` for workspace discard.
- Add quality-command documentation for Composer scripts and `Build/Scripts/runTests.sh`.
